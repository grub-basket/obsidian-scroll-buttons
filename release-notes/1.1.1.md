## 1.1.1

Fix: the scroll buttons no longer appear over non-Markdown panes (e.g. custom editor views from other plugins). The scroll target is now resolved strictly from the active pane and must be a Markdown editor, so the buttons always hide on non-editor views.

**Smart hide** is now the finer "hide when the current note is too short to scroll" check; non-editor panes always hide regardless of the setting.
