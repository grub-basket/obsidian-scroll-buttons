## 1.2.0

Attempted fixes for the open issues, plus a new caret-navigation feature.

### Fixes

- **Jump to bottom no longer stops early in Reading view** (#2). Embedded images/notes render lazily and grow the page after the scroll fires; the button now re-settles on the true bottom over the next few frames.
- **Buttons no longer silently stop working** (#4). If the workspace ever detaches the button container, it's re-attached on the next layout change — no more collapse/expand-the-sidebar workaround.

### New

- **Configurable scroll distance** (#3). A slider sets how far page up/down scrolls (as a percentage of the visible height), with an optional separate distance for Reading view.
- **Jump between cursor positions** (#1). Two new commands — *Jump to previous cursor position* and *Jump to next cursor position* — walk a history of where the cursor made a large jump (10+ lines, or a file switch). Bind them to hotkeys under Settings → Hotkeys.
